## 独享还是共享，未激活还是已激活 iCloud

这是前排文章讲得最含糊的两组概念，其实可以拆成四条判断。

**共享号**：一个账号多人共用，价格便宜，代价是被挤下线、密码被改、账号被锁的概率高，有效期只标 24 小时。适合“今天下完这个 App 就再也不登”的场景。

**独享号**：一个人独占，拿到账号、密码、密保问题和答案、生日，可以自己改密、绑自己的邮箱和手机号。要长期登录、要把它变成“自己的号”，只能选这个。

**未激活 iCloud**：只能登录 App Store 下载应用，不能登“设置”里那个 Apple ID 入口，也不能开 iCloud 同步。安全性相对高，因为不碰云端数据，账号出问题也不会锁住你的设备。绝大多数人买台湾 ID 就是下载用，这一档够。

**已激活 iCloud**：可以登设置、用 iCloud 同步、开查找我的 iPhone，功能完整，风险也更高。一旦账号出问题，设备上的 iCloud 数据可能被锁。未激活的号强行登设置会直接报错，不是操作问题，是账号类型不支持。

对应的决策规则：临时下一个 App，共享号；要长期登录、要改密绑手机，独享号；不碰 iCloud 同步，未激活版；必须用“查找我的 iPhone”，才考虑已激活版，并且接受它的风险。

完整流程按这个走：

1. 支付完成后在购买完成页或订单中心取账号信息，包含账号、密码、密保问题及答案、生日。
2. 用密保问题进入账号管理，先把自己正在用的手机号绑上去。
3. 打开 `https://appleid.apple.com/` 修改密码，这是苹果官方唯一改密入口。
4. 打开 App Store，点右上角头像进个人中心，下拉到底退出登录，再滑到顶部输入新账号密码直接登录。
5. **只登 App Store，不要登 iCloud。** 确有必要登 iCloud 的，登录后立刻关闭“查找我的 iPhone”。
6. 应用下载完，切回自己的主 ID 再打开应用。用买来的号长期挂着进游戏，容易出问题。

另外两条经验性提醒：一台设备不要同时挂太多外区 ID，频繁切换容易触发苹果风控；独享号不要拿去和同事朋友共用，一旦被多人登录，风控和被挤下线都会跟着来。
